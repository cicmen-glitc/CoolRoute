# CoolRoute

CoolRoute — веб-приложение, которое помогает находить более комфортные
пешеходные маршруты в жару и отмечать перегретые места в городе.

## Проблема

Глобальное потепление делает волны жары более частыми и опасными.
Горожанам нужна практичная защита уже сегодня: тень, зелёные зоны,
доступ к воде и менее перегретые улицы.

| Проблема | Решение CoolRoute |
| --- | --- |
| Людям тяжело переносить экстремальную жару | Карта и маршруты помогают выбирать улицы, где рядом есть зелень и вода. |
| Города перегреваются из-за асфальта и нехватки деревьев | Отметки жителей помогают находить места, которым нужны деревья и навесы. |
| Пешие прогулки в жару некомфортны | Приложение сравнивает короткий маршрут с альтернативами по ориентировочному индексу комфорта. |
| Городским службам не хватает местных наблюдений | Сводка показывает участки с наибольшим количеством сообщений о жаре. |

## Возможности

- Поиск адресов и выбор точек маршрута на интерактивной карте.
- Поиск города и адресов по названиям на разных языках и в разных письменностях.
- Поиск города и загрузка погоды, зелёных зон и отметок для выбранной области.
- Определение текущего местоположения как точки отправления маршрута.
- Пешеходные и велосипедные маршруты: короткий и с наилучшей оценкой комфорта.
- Индекс маршрута по длине, времени, погоде, зелёным зонам и точкам воды.
- Карта зелёных зон, деревьев, фонтанов и питьевой воды из OpenStreetMap.
- Сообщения жителей о жарких участках и агрегированная панель приоритетных мест.
- Текущая температура и ощущаемая температура.
- Адаптивный интерфейс для компьютеров и телефонов.

## Как это помогает климату

- Снижает риск перегрева для пешеходов и велосипедистов.
- Делает экологичный транспорт более комфортным.
- Помогает городам приоритизировать деревья, навесы и зелёные зоны.
- Превращает данные жителей в конкретные городские улучшения.

## Технологии и источники данных

- Python 3.10+ и FastAPI — backend.
- SQLite — сообщения жителей (файл базы создаётся автоматически).
- Leaflet и OpenStreetMap — карта.
- OpenStreetMap Nominatim — поиск адресов.
- OpenStreetMap routing.openstreetmap.de — пешеходные маршруты.
- Overpass API / OpenStreetMap — зелёные зоны, деревья и места с водой.
- Open-Meteo — текущая температура и ощущаемая температура.

Для поиска, маршрутизации, карты и погодных данных требуется подключение
к интернету. Внешние публичные сервисы могут ограничивать частоту запросов.

Индекс комфорта — ориентировочная оценка прототипа, а не медицинская
рекомендация. Доступность парков, деревьев и воды зависит от полноты
OpenStreetMap; фактическая тень и температура поверхности пока не измеряются.

## Запуск в Windows

1. Установите Python 3.10 или новее с сайта https://www.python.org/downloads/.
   При установке включите добавление Python в PATH.
2. Откройте папку проекта в PowerShell.
3. Запустите:

   ```powershell
   .\run.bat
   ```

   Скрипт создаст виртуальное окружение, установит зависимости и запустит сайт.
4. Откройте http://127.0.0.1:8000.

Для ручного запуска:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn backend.app:app --reload
```

Остановка сервера: `Ctrl+C` в окне PowerShell.

## API

- `GET /api/geocode?q=...` — поиск адреса.
- `GET /api/cities?q=...` — поиск города.
- `GET /api/routes?start=долгота,широта&end=долгота,широта&mode=foot` — пешеходный маршрут.
- Для велосипеда укажите `mode=bike`.
- `GET /api/weather?latitude=...&longitude=...` — текущая погода.
- `GET /api/places?latitude=...&longitude=...` — объекты зелени и воды.
- `GET /api/reports` и `POST /api/reports` — сообщения о жаре; GET можно ограничить координатами города.
- `GET /api/city-insights` — сводка и места с наибольшим числом отметок в городе.
- `GET /docs` — интерактивная документация FastAPI.
